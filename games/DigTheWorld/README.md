# DIG THE WORLD — Roblox prototype

A mobile-friendly digging simulator prototype for Roblox Studio.

## World setup
- Exact surface field: **15 × 15 blocks** (225 starting blocks)
- Underground depth: **300 layers per column**
- Each layer is 4 studs tall; maximum dig depth is 1,200 studs
- 12 geological visual bands, with 300 individually numbered layer levels

## Included
- Server-authoritative digging with distance checks and cooldowns
- Procedural 15 × 15 dig field with layered underground blocks
- Coins, shovel upgrades, finds and DataStore persistence
- Mobile dig button plus keyboard/mouse controls
- Upgrade and sell interaction zones
- Lighting and atmosphere setup

## Install
1. Open a Baseplate in Roblox Studio.
2. Create the scripts/folders described in the project tree and copy each Lua file into its matching Script or LocalScript.
3. Enable **Game Settings → Security → Enable Studio Access to API Services** for save testing.
4. Publish the experience from Studio.

**Status:** project source files are in this repository. The place has not yet been opened, tested, or published in Roblox Studio. Custom mesh assets, animated NPCs, and a finished large world are not included yet.
