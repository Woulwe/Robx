# DIG THE WORLD — Roblox prototype

A mobile-friendly digging simulator prototype for Roblox Studio.

## Included
- Server-authoritative digging with distance checks and cooldowns
- Procedural dig field with layered soil and collectible finds
- Coins, shovel upgrades, inventory and DataStore persistence
- Mobile dig button plus keyboard/mouse controls
- Upgrade and sell interaction zones
- Lighting and atmosphere setup

## Install
1. Open a blank Baseplate in Roblox Studio.
2. In Explorer, create the scripts/folders described below.
3. Copy each Lua file into the matching Script or LocalScript.
4. Enable **Game Settings → Security → Enable Studio Access to API Services** for save testing.
5. Publish the experience from Studio.

This is a playable first prototype. It does not yet include custom mesh assets, animated NPCs, or a finished large world.
